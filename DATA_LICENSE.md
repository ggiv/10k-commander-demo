# Data and source treatment

This repository contains **no real company data**. It is source code published for reference only; it makes no claim to provide, and does not distribute, SEC filings, financial figures, company lists, or analysis of real companies.

The fictional data in `tests/fixtures/`, including synthetic SEC-shaped payloads and hand-worked expectations, is dedicated under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Fictional filing/accession URLs are illustrative and do not point to real filings. Fixture-generation code is covered by the repository's MIT license.

If you run the SEC retrieval commands yourself, the data you download remains subject to the source's own terms; this repository asserts no ownership or redistribution license over it. Review those terms before sharing any capture, and prefer factual extracts, attribution, and source links. Do not commit captures, release archives, or credentials.

Source references: [SEC EDGAR API documentation](https://www.sec.gov/search-filings/edgar-application-programming-interfaces), [SEC access guidance](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data).
